Cross-Cutting Backend Standards

Every collection endpoint should support:

Pagination
?page=1&limit=20
Sorting
?sort=name
?sort=date
?sort=rating
?sort=confidence
Filtering
?status=
?risk=
?city=
?specialization=
Search
?q=melanoma
Standard Response Format
{
  "success": true,
  "message": "Operation completed successfully.",
  "data": {},
  "pagination": {}
}
Standard Error Format
{
  "success": false,
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "Requested resource was not found."
  }
}
